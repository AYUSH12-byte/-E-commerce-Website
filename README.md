# Acrux - Luxury Watches E-commerce Website

A modern, responsive e-commerce website for luxury watches built with HTML, CSS, and JavaScript.

## 📋 Overview

Acrux is a premium watch e-commerce platform featuring a clean, elegant design focused on showcasing luxury timepieces. The website includes product displays, team portfolios, blog content about watchmaking technology, and research sections.

## 🎨 Features

- **Responsive Design**: Mobile-first approach with flexible layouts
- **Hero Banner**: Eye-catching homepage with background image
- **Product Catalog**: Showcase of luxury watches
- **Team Portfolios**: Individual pages for team members
- **Blog Section**: Multiple articles about watchmaking technology
- **Research Page**: Dedicated research content
- **Modern UI**: Clean, professional design with hover effects

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Styling with Flexbox, Grid, and responsive design
- **JavaScript**: Interactive functionality and DOM manipulation

## 🚀 Getting Started

### Prerequisites

- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No server required - runs as static files

### Installation

1. Clone or download the project files
2. Open `index.html` in your web browser
3. Navigate through the site using the menu links

### Development

Since this is a static website, you can:
- Open files directly in a browser for testing
- Use a local server like Live Server in VS Code for better development experience
- Edit HTML, CSS, and JS files with any text editor

## 📱 Pages

- **Home** (`index.html`): Landing page with hero section
- **About** (`about.html`): Company information and team members
- **Products** (`product.html`): Watch catalog and details
- **Blog** (`blog.html`): Technology in watchmaking articles
- **Research** (`research.html`): Research content
- **Portfolio**: Individual team member profile pages

## 🎯 Key Components

### Navigation
Consistent navigation across all pages with links to main sections.

### Hero Section
Full-screen banner with overlay text on the homepage.

### Product Display
Grid layout for showcasing watch products.

### Team Section
Profile cards for team members with hover effects.

### Blog Layout
Article-style layout for blog content.

## 📸 Assets
